# Kale documentation / Kale belgeleri

Kale is a central authentication and authorization service (AuthService), a thin client package for applications (`Kale.Auth.Client`), and an admin UI.

Kale; merkezî bir kimlik doğrulama ve yetkilendirme servisi (AuthService), uygulamalar için ince bir istemci paketi (`Kale.Auth.Client`) ve bir yönetim arayüzünden oluşur.
